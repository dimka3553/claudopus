- No task or helper can start a command whose only job is to wait, whatever shape it takes: a loop that keeps checking for a file, a line, a page or a command, a long sleep, a wait on a process, a tool made to wait, a log followed until one line comes, or a short script that only polls. Claudopus refuses it in one sentence that says what wakes Claude instead. This now covers helpers too, which is where the "36 tries · waiting for sheets" rows came from.
- A task no longer waits for its helpers ("Wait for the three builders"). It ends its step and carries on when each helper's result comes. Seen live: when a task ends its step, the app hands the helper's result to the chat. Claudopus now passes it on to the task, starts the task again, and tells the chat there is nothing to do.
- For a file, a page or a time that nothing of Claude's own makes, Claude asks Claudopus to wake it (`wake_me`). Claudopus looks every 15 seconds and starts Claude again once it is there, or says it never came. Meanwhile the card says what Claude is waiting for, in place of a command row.
- A real retry (a push or a copy tried again), a batch that pauses between items, and every ordinary long command still run.
