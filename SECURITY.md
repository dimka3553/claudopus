# Security

Claudopus runs hooks inside Claude Code on your Mac, so a security problem in it matters.

Report one privately through [GitHub's private vulnerability reporting](https://github.com/dimka3553/claudopus/security/advisories/new), not in a public issue.

What Claudopus runs, which network calls it makes and which files it keeps are written down in [the privacy page](mods/claudopus/docs/privacy.md).
